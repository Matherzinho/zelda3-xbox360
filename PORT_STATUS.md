# Xbox 360 port status

Community Xenon port based on `snesrev/zelda3` baseline `45a149d8b4bb8098f53d1009f76e76e7d8b79bbf`. The original MIT license and upstream credits remain in `LICENSE.txt` and the upstream README. This project is not affiliated with Nintendo or Microsoft.

## Implemented

- Xenon CMake target and XSDK XEX packaging.
- Shared game initialization, update and render interfaces in `src/game.c` and `src/game.h`, retaining the PC frontend.
- Xbox frontend and XSDK GPU renderer under `xbox360/`, including PPU frame-buffer submission and controller mapping.
- Diagnostic stage logging for assets, game initialization, GPU and presentation.

## Not validated / limitations

- A Zelda XEX was generated by the XSDK toolchain.
- Xenia Canary exits during `xsdk_present_open` with display LUT autofill status `0xC00000B5`; the minimal XSDK presentation sample reproduces this failure.
- No successful in-game frame or physical console run has been confirmed.
- Audio, settings menus and image options are not validated.
- The current build references external XSDK and SDL-xenon paths specific to the development machine.

## Legal assets

Provide your own legally obtained compatible US Zelda 3 ROM and generate `zelda3_assets.dat` locally as described in [BUILDING_XBOX360.md](BUILDING_XBOX360.md). Do not commit or distribute the ROM or extracted asset file.
